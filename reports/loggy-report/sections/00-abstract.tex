The Event Processing Nodes (EPNs) form the ALICE computing farm that runs timeframe reconstruction. Logging on the EPNs is currently handled by InfoLogger, which carries only the messages a process sends to it, so log files written to disk and the system journal are never collected. The records that do reach InfoLogger are stored in a single central table, with no aggregation over time, one retention policy and no replication, and shifters inspect them by hand. The aim of this work is a single place to search and monitor every log of the farm without drawing resources from timeframe reconstruction.

For this purpose, a log platform named \loggy{}, based on Fluent Bit and OpenSearch, was developed and deployed with Ansible. A collector on each worker reads every log source and stamps each line with its message template. Lines are then routed by severity: the bulk of the volume is indexed on the worker that wrote it and never crosses the network, while the lines that matter and every InfoLogger record go to a small replicated storage tier. Workers and storage nodes form a single OpenSearch cluster, so federated search is handled by default. Anomaly detection is applied both to the metrics and, through the message templates, to the log text itself. Alerts are merged into episodes and passed to Alertmanager for notification. Semantic search over the templates lets an operator find a message by its meaning.
